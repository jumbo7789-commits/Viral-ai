# ViralCut AI

A £0-first starter for preparing YouTube Shorts from gameplay footage you own or are licensed to use. Includes Python CLI metadata generation, FFmpeg vertical editing, public YouTube metadata research, optional OAuth upload helper, and GitHub Actions validation.

## Important limitations
This is a starter scaffold, not a fully autonomous viral-video system. It does not automatically download other creators' videos, identify viral moments with AI, generate narration, or guarantee views or monetisation. Only use footage and audio you own or have permission to use. Follow YouTube copyright and reused-content rules.

## Setup
See SETUP.md. Requires Python 3.11+, FFmpeg, and optional Google OAuth credentials for uploading. Uploads default to private. Never commit API keys, OAuth credentials, or tokens.
